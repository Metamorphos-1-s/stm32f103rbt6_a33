## 同一权威块的均值分解

比较加载前 `[−45,−15)` 与卸载后 `[15,45)`；
`Δnet = Δuncompensated − Δapplied_offset − Δtare`，本次 Δtare = 0。
中位数差独立计算，不要求中位数满足加法等式。单位 g：

| 轮次 | 补偿前均值变化 | offset 均值变化 | 补偿后均值变化 | 净重中位数变化 |
| --- | ---: | ---: | ---: | ---: |
| 1 | +0.047520 | +0.037359 | +0.010161 | +0.010604 |
| 2 | +0.083681 | +0.041590 | +0.042091 | +0.042973 |
| 3 | +0.014969 | +0.022778 | -0.007809 | -0.009129 |

这些是同一实际输入轨迹上的算术分解，不等同于 R5 OFF 的独立物理对照。
第 2 轮残差确实存在；补偿前已经有约 +0.083681 g 的变化，R5 offset 同期
增加约 +0.041590 g，实际输出剩下约 +0.042091 g。不能把这说成 R5 已经
改善实际回零资格，也不能说残差全部由显示层或 R5 引入。

不同等待时间的净重中位数差（相对同一轮加载前，单位 g）：

| 轮次 | 卸载后 15–45 s | 卸载后 60–90 s | 卸载后 90–120 s |
| --- | ---: | ---: | ---: |
| 1 | +0.010604 | +0.011168 | -0.004696 |
| 2 | +0.042973 | +0.031921 | +0.033536 |
| 3 | -0.009129 | -0.023450 | -0.020255 |

第 2 轮到 90–120 秒仍约 +0.033536 g，第 3 轮同龄窗口约 −0.020255 g。
不能只用最早窗口或最终一次空载读数宣布回零收敛。加载前绝对空载偏置
（约 0.36–0.41 g）与一次装卸的回零差是不同指标；本轮未执行 ZERO/TARE，
也没有给出可用于判定 PASS 的回零容差。

## R5 机制核对

当前构建把 R5 接口映射到 `Domain/measurement/a13c_shadow_compensator.c`，
不是旧版 reference_lock 控制器。`FeedStatic()` 在明显阶跃后重新建立参考，
以 `mass - offset` 填充参考历史，随后按观测历史更新 offset。
因此 R5 的当前目标是跟踪各静态平台的慢漂移；它不保存最初空载值作为
每次卸载必须回到的目标。不能仅增大显示保持阈值来修复这个计量问题。

三轮卸载后 `[15,45)` 的实际 offset 分别恒定为 +24,780 / +59,337 / +69,968 ug。
新的 reference-lock 诊断首次出现在卸载约 46.407 / 46.359 / 48.047 秒后。
权威块中首次观察到 offset 改变分别在约 99.782 / 68.781 / 73.297 秒后。
这些是轮询观察时间，诊断与 authority 不是同一次请求，不能当作精确的
固件事件时间或把旧的 first_correction_sequence 直接解释为本轮新事件。

早期 offset 的前后差包括加载期间累积的变化，不能说是卸载后立即追调。
此机制与现场数据相符；机械恢复、温漂、传感器迟滞及其相互影响仍无法分离。
