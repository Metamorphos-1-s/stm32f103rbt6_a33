# A33 0x0533：大阶跃跟随、零点灯、配置迁移

基线：`0x0532`，提交 `5b1b16d7969f224d649abc627d313de478323f51`。
候选预设 `Stage5PFastFollow`，Modbus Map `0x0110`。

- **10 Hz / FILT1**：从已稳定的台阶出发，两次相邻真实采样相对旧滤后值同向变化至少 10 g，彼此差不超过 0.1 g，间隔不超过 150 ms。取旧锚点和两个新值的中值重置滑动平均历史。第二个样本起可以跟随新平台；稳定窗重新用真实样本积累，原保持时间不变。单点尖峰、方向反转、样本中断和两点间明显移动不触发。仅在正常称重、启动置零完成、无故障时使用，两点都要通过 ADC 余量和正常毛重越限检查；CAL、40 Hz 和其他滤波档走原路径。
- **零点灯**：`0x0532` 在判稳以后才开始 1000 ms 的近零确认。`0x0533` 对 R5 修正后的最终净重执行 300 ms 近零确认，可以在官方判稳候选阶段同时计时。净重连续处于 ±2d、且官方 STABLE 成立时才点亮；保持的 ±3d 边界沿用。若近零较晚，两灯仍可先后亮。
- **V3 → V4**：烧录或启动时只读旧配置。无编辑时，菜单列表长按 FUNCTION 或发一次明确的 SAVE，可将当前有效配置提交到另一槽，先写 CRC 和数据，最后提交并校验；不擦除原活动槽。首次迁移后，配置无变化的 SAVE 仍走原有的 no-op。已发生改动的正常保存也会写 V4。配置 schema 改变不清除实际 CAP、记录的传感器额定容量、标定或通讯参数。原 V3 默认判稳时间的既有归一化规则仍适用。
- **CAL 上限**：CAL 输入砝码重量不能大于当前保存的 CAP，也要能按当前单位与分度表示。若在 CAP 编辑时就被拒绝，读回额定容量已知位（`0x0117 bit0`）、额定容量（`0x0118–0x011B`，µg）、当前 CAP（`0x0104–0x0107`，µg）、单位/小数位和已有标定跨度。若额定容量实际配置为 3000 g，V4 也会保留。依据实物额定量核对或更正该配置，再单独检查 CAL，勿把迁移和改量程混成同一次试验。

风险：两个相近的冲击或振动采样仍可能触发一次快跟随，短时显示可能提前跳动；机械响应缓慢时，反而可能不满足两点条件，回到普通滤波。不会因快跟随直接判稳。较短的近零确认可能在阈值附近更早亮灯，OFF 条件和真实 STABLE 仍有效。迁移首次会擦写备用槽，现场操作前保留完整配置区备份。

软件证据：ARM Release 编译和静态栈门限通过（保守余量 536 B）；Host 53 项通过。合成 10 Hz / FILT1 / strength3 的 500 g 阶跃，稳定灯从阶跃后的 1200 ms 到 1100 ms；卸载时 STABLE 和 ZERO 均在 1100 ms 成立。这是合成平台，未在仪表实测。单点冲击和仍在变化的两点未触发跟随，模拟 Flash 验证了干净 V3 可通过显式保存迁移，且原槽内容和标定保持。
