# A33 0x0532：10 Hz 判稳候选

基于 `0x0531` 固件提交 `71ec6b64597fa13803428c0a30228781294227dc`。
Modbus Map 保持 `0x0110`。

- 10 Hz 判稳不再用四段均值的微小同向变化否决稳定，也不等待这四段均值填满。仍由原有短窗极差、进入/退出阈值和保持时间判稳。保留原始值与滤后值差异过大的否决和采样间断重置。
- 40 Hz 仍使用 `0x0531` 的趋势检查。稳定灯、零点灯以及使用 STABLE 的功能仍消费同一正式状态；没有添加灯的强制保持。零点灯自己的近零阈值和等待时间不变。
- 300 ms 是正常称重的默认保持时间，保留原有可配置项。本次不改采样、滤波、标定、R5、菜单或容量校验。
- 10 Hz 对非常缓慢的单向加料不再有独立趋势否决，窗口内的微小变化可能报稳。实际灯闪原因与改善程度未在板上确认。
