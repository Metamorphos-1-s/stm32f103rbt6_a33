# A33 0x0537：滤波跟随和保存恢复

候选基线 `0x0536` / `ae1dd2514f8b4f18dcf8d711b628b6f99e595386`；ARM 构建预设 `Stage5PFilterRecovery`。保留 CAP 独立设定，Modbus Map `0x0110`、配置格式 V4。

10 Hz 下 FILT2／FILT3 在最后一个正式稳定样本后保留旧平台 1 秒。相邻原始样本至少变化 10 g，且新样本离开旧平台至少 10 g，才开启阶跃候选。随后在同一侧用连续两条真实样本确认（差值不大于 0.1 g）；可以在窗口内继续等到新平台。回到旧平台、反向、断样、失效、超时等会取消本次候选。通过后重置滤波输出和判稳窗口；稳定灯、零点灯仍按原有规则重新判定。FILT1 保持原逻辑。

只改当前滤波模式／强度并且 ADC 正常时，配置保存不会让 CS1237 进入安全停机或重新启动。保存期间继续读取 ADC 并丢弃暂存数据，保持原有重量和检重输出隔离。退出前检查 ADC 仍在运行且缓存的硬件配置回读匹配；否则走原重启路径。保存开始时旧样本仍需满足 250 ms 新鲜度，合格的旧滤后值最多允许沿用至距该样本 500 ms。首条新的有效数据到来前，旧数字只用于面板过渡，不生成有效重量。超出限时、故障或没有合格旧样本时，仍可正常显示等待或错误状态。

Host 56 项通过，包括四段边沿、缓坡、冲击、候选超时、模拟 200 ms 保存加下一次采样的显示过渡、CAP 保存和 CAL。另用模拟 ADC 验证了实际 DeviceManager 代码的继续采样、丢弃暂存以及校验不匹配时的回退。ARM Release 构建通过，静态 RAM 19,520 B、保守嵌套栈余量 536 B（门槛 512 B）。未实板烧录，保存期间的 COM5 超时仍需单独复测。
