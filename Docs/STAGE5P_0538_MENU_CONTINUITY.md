# A33 0x0538：菜单保存后的称重连续性

基线 `0x0537` / `af63edcb9ef00cb52d3af73fbfeea5f1b0f150d0`；构建预设 `Stage5PMenuContinuity`。Modbus Map `0x0110`、配置格式 V4。

`0x0537` 实板确认：单改滤波，FUNCTION 确认后短按 TARE 退出没有 `bUSY`；CAP 可设 6000 g；单改 dP 或 CAP 后退出短暂显示 `bUSY`。原因是旧版只在“单改滤波”时保留 ADC，其他保存会停 ADC；CAP、dP、分度等还会重建软件称重链路并清除当前重量。

`0x0538` 普通保存统一比较待保存的 ADC 配置与硬件最近的有效读回。配置一致、ADC 就绪且无故障时，不重启 ADC；保存期间继续采样并丢弃缓冲数据，不把维护期间样本送入计量。退出时再次核对 ADC，失配按原逻辑重启。候选保存实际重启 ADC 时，称重链路也重新等待有效数据。校准保存和恢复出厂继续走原流程。

在现用档位、滤波、采样率、增益、判稳参数和校准不变时，CAP、dP、分度、单位等就地更新；保留滤波状态、质量值和已应用的 R5 补偿。新 CAP/分度导致超载时立即应用新上限，清除 ZERO，退出 R5 ACTIVE；新分度的 ZERO 必须重新由新样本确认。若保存引入采样间隔，沿用原有 R5 缺口恢复逻辑：保留已应用偏移，重建学习参考。不兼容的采样设置、故障、没有有效称重数据，或新旧显示比例不一致且滤波等也发生改变时，仍允许显示真正的等待状态；不会用新小数点解释旧计数。

## 显示跳字与漂移补偿

R5 使用未补偿的滤波质量（µg），不会读取 dP 或分度来切换其补偿门限、速率或上限。dP/分度改变的是有效显示格、显示防抖判据、ZERO 的分度相关范围，以及 `CAP+10d` 超载边界（通用模式，以 g 分度计算）。因此极接近超载边界时，可通过超载门控间接影响补偿。此前版本的普通配置重建还会让 R5 重新建参考。

以 g、分度数为 1 为例：真实值在 0.044–0.056 g 间波动，直接量化到两位小数时为 0.04–0.06 g，量化到一位小数时跨过 0.05 g 边界，显示可在 0.0 与 0.1 g 之间跳。实际面板还有自适应防抖和持续时间条件；一次 0.1 g 跳字不能单独证明真实值变化了 0.1 g。比较时固定载荷和滤波，在 0.00 / 0.0 两档记录未补偿质量、补偿后质量、R5 offset、面板数值及跳字时刻。

57 项主机测试通过，覆盖按键 CAP、dP、分度、置零范围、亮度、蜂鸣器的保存退出，以及采样率变更后的重新采样、CAP 下调的即时超载保护。ARM 构建通过：静态 RAM 19,520 B，静态保守嵌套栈余量 520 B，门槛 512 B。候选尚未上板。
