# A33 0x0536：CAP 独立设定

候选基线：`0x0535` / `7bbee51d7214b4fa517a67a00e70fafbeef0a741`。构建预设 `Stage5PCapOnly`，Modbus Map `0x0110`，配置格式 V4。

从本版开始，传感器额定容量只保留为旧设备和客户端的兼容信息。即使旧配置将其登记为 3000 g，CAP 也可以在显示与计量参数允许的范围内单独设定。无须先更改额定容量、清除旧配置或恢复出厂。原字段、已知位、历史值和寄存器地址均保留；不会在升级时自动改写 Flash。CAP 的出厂默认仍是 3000 g。

CAP 必须为正、在已启用单位的显示范围内，并且不能低于已生效的标定跨度。CAL 的输入上限仍取已保存的 CAP；通用模式的显示超载阈值仍取 CAP + 10d。本版不改标定结果、滤波或 `bUSY` 行为。设定 CAP 不改变秤体和传感器的承载能力。

Host 共 55 项通过。新用例用保留 3000 g 旧额定值和 500 g 标定跨度的 V4 记录启动，经过实际按键处理代码保存 `6000.0 g` 或 `6000.00 g`；验证一次保存、重新加载配置、进入及取消 CAL、保留原标定和元数据。另验证 `11000.00 g` 仍超出六位显示范围、`400 g` 仍低于已保存的标定跨度。ARM Release 构建通过，静态保守嵌套栈余量 536 B（门槛 512 B）。尚未进行实板验收。

实板验证建议：先备份 4 KiB 配置区 `0x0801F000–0x0801FFFF`，只擦应用页 `[0 123]`，向 `0x08000000` 写入、Verify 并复位。通过 COM5 核对固件版本和升级前后配置区，再用面板将 CAP 改成 `6000.0` 或 `6000.00`，短按 FUNCTION 确认，短按 TARE 退出；重读 CAP 及保存序号。可打开 CAL 检查能否进入后取消，不需要完成标定，也不需要放 6 kg 砝码。如果以后降回 `0x0535`，先把 CAP 改回旧版可接受的范围，或恢复升级前的配置备份；否则旧版可能拒绝加载含有超额 CAP 的槽。
