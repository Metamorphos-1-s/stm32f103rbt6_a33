# A33 0x0541：修复 noCAL 按键音

基线：`0x0540` / `b364bb3473f7a6698e326c40fad5dd29661544ee`。构建预设 `Stage5PKeyBeepContinuity`。Modbus Map `0x0110`、V4 配置格式、标定和称重算法均沿用基线。

未标定或没有有效重量时，检重按无效样本解除输出，灯和报警蜂鸣器保持关闭。已经触发的内置按键短鸣保留原来的 40 ms，不再被 20 ms 检重任务提前清除。Flash 维护结束后，即使还没有有效重量，也会确认检重进入重新等待状态并解除按键音的等待标志。真正进入故障态时同时清空输出管理器状态和 GPIO，避免定时任务重新打开旧输出。Flash 维护中关闭输出，已生效的连续报警仍优先于按键音。

使用实际按键消抖、调度器、检重更新逻辑、计量和 GPIO 软件路径回放。首次保存场景使用空白假 Flash，通过保存管理器完成实际配置写入和维护退出。

| --- | ---: | ---: |
