# A33 0x0535：滤波切换与自适应显示

基于 `0x0534` 提交 `901b58da2673e161024e18454e60309dfbd60138`。
ARM 预设 `Stage5PAdaptiveDisplay`，Modbus Map `0x0110`。本版为实板待验候选。

- **FILT1／2／3 大阶跃**：沿用 0x0534 在 10 Hz 下的两点快速跟随条件和原判稳时间。两点都是真实采样；单点尖峰不触发。两次相似的冲击仍可能短暂触发跟随。
- **切换滤波连续显示**：短按 FUNCTION 确认到待保存配置；短按 TARE 退出时合并写一次 Flash。滤波模式或强度单独修改时，从原滤波器最后一条有效、稳定的滤后 ADC 值预填新滤波器。种子距当前最多 250 ms，保存重启采集时沿用。面板短暂保留同一称重页的旧数，首条真实采样到达后恢复正常发布。保留旧数字期间 `WEIGHT_VALID`、`STABLE`、`ZERO` 均不置位。量程/分度、标定、速率、增益等变化不预填。已标定但暂未有有效重量时显示 `buSY`；真正未标定时仍显示 `noCAL`。
- **显示防抖**：稳定且无明显趋势时，从未舍入的权威重量估计噪声。每个窗口取 9 条新样本，去掉两端各一个值，使用剩余极差的一半估算并平滑。噪声带有上限，不随持续加料放大。舍入边界附近加回差；变化明显时三条同向新样本就跟随，持续跨过同一边界约 600 ms 也跟随，超过 8 个显示分度的跳变直接发布。只调整显示层，不改正式判稳规则、Modbus 权威重量、检重/报警逻辑或配置记录格式。

Host 54 项通过。集成用例通过 FUNCTION/TARE 实际菜单路径切换滤波，核对 Flash sequence 只增一次、旧数字连续、真实首条样本才发布有效重量。模拟显示用例覆盖 ±0.02 g 抖动、0.1 g 舍入边界、0.01 g 细分度、持续缓变和 0.2 g 加载。以 10 Hz 的合成 500 g 阶跃测得 FILT1/2/3 的 STABLE 均为 1.10 s；模拟卸载时 STABLE、ZERO 同时成立。这些时序并非实板指标。

ARM Release 构建通过。静态 RAM 19,520 B；保守嵌套中断栈余量 520 B（门槛 512 B），尚无运行时水位数据。
