# 1. 产品简介

## 1.1 产品用途

本仪表以 STM32F103RBT6 为控制核心，用于连接应变式称重传感器，将传感器信号转换为六位重量显示，并提供本地操作、参数设置、两点标定、上下限检重和有线/无线通讯功能。仪表适用于需要现场显示、置零、去皮、检重输出和上位机数据采集的称重设备。

本仪表不是机械过载保护装置，也不是未经配套秤体和 Stage 6 验证即可直接宣称计量等级的完整衡器。

# 2. 安全与使用注意事项

## 2.1 安装与接线

1. 传感器、通讯线和外部输出接线前应断开仪表电源。
2. 接线前确认传感器的 E+、E-、S+、S- 定义，禁止仅按线色推断。
3. 电源极性、电压和端子位置必须以对应硬件版本丝印及配套硬件资料为准。
4. RS232/RS485 通讯应按现场条件处理共地、屏蔽、线缆走向和浪涌干扰。
5. RS485 长线或多节点网络是否加终端电阻、偏置电阻，应按总线拓扑和现场实测确定。
6. BLE 模块位于仪表内部，普通用户不需要对 W02 进行硬件接线或发送 AT 命令。

## 2.2 称重与标定

1. 不得让传感器承受超出其机械允许值的载荷、冲击或侧向力。
2. `OL` 是仪表的软件过载判定值，不等于传感器机械安全极限。
3. 标定应使用质量值可靠、适合当前量程的已知砝码，并保持秤台无振动、无碰触。
4. 标定示例中的 500 g 仅用于说明步骤，不代表所有量程均推荐使用 500 g。
5. 建议采用足够大且可靠的已知质量作为加载标定点；最终推荐比例以 Stage 6 结果为准。
6. 更换传感器、改变机械结构或明显调整安装状态后，应重新标定并校验。

## 2.3 保存与供电

1. 参数按 FUNCTION 确认后通常立即在 RAM 中生效，但必须执行 `SAUE` 才能保证掉电保持。
2. 屏幕显示 `SAUE` 或正在执行保存/恢复时，不要主动断电。
3. 显示 `ErrSAU` 时，本次保存未被确认成功；应检查供电、重新执行 SAVE，并在必要时联系维护人员。
4. ZERO/RESET ZERO 为易失操作，掉电后不保留。
5. TARE 是否能在掉电后恢复由 `trrEt` 设置决定；开启后，执行 TARE/CLEAR TARE 还需再次 SAVE 才能保存新皮重状态。

## 2.4 计量性能说明

显示 `0.01 g` 只表示当前小数点和分度允许该显示格式，不表示仪表已经达到 `0.01 g` 的实际准确度。推荐预热时间、分度、小数位、滤波和稳定参数将在 Stage 6 计量性能验证完成后于 V1.0 说明书中补充。

# 3. 产品接口与安装

## 3.1 接口总览

由于 V0.9 尚未冻结正式外壳和端子排图，本章给出逻辑接口。**端子位置以对应硬件版本丝印为准。**

**[图片占位：图 3-1 接口定义，后续替换端子排实物图]**

| 接口 | 信号 | 用途 | 注意事项 |
|---|---|---|---|
| 传感器 | E+、E- | 传感器激励 | 极性按传感器资料确认 |
| 传感器 | S+、S- | 差分测量信号 | 避免与动力线并行长距离敷设 |
| RS485 | A、B、GND（如硬件引出） | 半双工 Modbus RTU | A/B 命名可能因设备厂商不同，接反时无法通讯 |
| RS232 | TX、RX、GND（如硬件引出） | 点对点 Modbus RTU | TX/RX 应交叉连接 |
| 电源 | 以硬件丝印为准 | 仪表供电 | V0.9 不在无资料时声明电压范围 |
| 外部蜂鸣器 | 以硬件丝印为准 | 检重报警输出 | 受 `bEH` 控制 |
| BLE | 内部 W02 | 无线数据和命令 | 无需用户接线 |

## 3.2 传感器连接

典型四线传感器连接关系如下：

```text
仪表 E+  ───────── 传感器激励正
仪表 E-  ───────── 传感器激励负
仪表 S+  ───────── 传感器信号正
仪表 S-  ───────── 传感器信号负
```

接线后若加载方向与显示方向相反，不应随意交换激励端。应由有资质的调试人员核对传感器接线和标定结果。本固件的标定模型可处理正向或反向的原始信号变化，但接线仍须符合硬件要求。

## 3.3 RS485 连接

```text
上位机/PLC A  ───────── 仪表 A
上位机/PLC B  ───────── 仪表 B
信号地 GND    ───────── 仪表 GND（如引出）
```

**[图片占位：图 3-2 RS485 连接示意，后续替换正式接线图]**

RS232 与 RS485 在当前硬件上共享 USART2 数据、地址、CRC、功能码和寄存器表。具体使用哪种电气接口取决于外部硬件选择，固件不读取外部接口选择器。

## 3.4 上电检查

1. 确认传感器和通讯线无短路、松脱和反接。
2. 清空秤台，确保无外力接触。
3. 接通电源，观察启动自检。
4. 自检后若显示 `noCAL`，按第 10 章进行标定。
5. 若显示 `OL` 或 `Err`，先断电检查接线和机械载荷，再按第 15、16 章排查。

# 4. 面板与显示说明

## 4.1 面板组成

面板包含六位数码管、单位/状态指示、外部黄绿红检重灯和五个按键：FUNCTION、TARE、ZERO、STAR、HASH。

**[图片占位：图 4-1 面板示意图（后续替换实物图）]**

```text
┌──────────────────────────────────────────────┐
│  [  0  0  0  0 . 0  0 ]   kg / g / lb     │
│  状态：NET GROSS TARE STABLE ZERO BATTERY   │
│  检重：YELLOW   GREEN   RED                 │
│                                              │
│ [FUNCTION] [TARE] [ZERO] [STAR] [HASH]      │
└──────────────────────────────────────────────┘
```

**[图片占位：图 4-2 五键布局，后续替换面板丝印图]**

## 4.2 重量与页面

正常称重时，FUNCTION 短按依次切换：

```text
NET（净重） → GROSS（毛重） → TARE（皮重） → BATTERY（电源监视） → NET
```

HASH 短按可在 NET 和 GROSS 之间快速切换。

| 页面 | 含义 |
|---|---|
| NET | 当前净重，净重 = 毛重 - 皮重 |
| GROSS | 当前毛重，不扣除皮重 |
| TARE | 当前保存于运行状态的皮重值 |
| BATTERY | 电源监视值；无法取得有效值时显示 `------` |
| STATUS | 维护状态页；STAR 长按进入 |

## 4.3 状态指示

面板内部状态指示包括 NET、GROSS、TARE 页、STABLE、ZERO、BATTERY、未标定、过载和菜单状态。它们与外部黄/绿/红检重灯不是同一组指示。

- **STABLE**：当前重量判断为稳定。它不等于显示锁定，也不代表已完成 Stage 6 计量确认。
- **ZERO**：当前重量处于零点状态。
- **TARE active**：当前存在有效皮重。
- **MENU**：当前处于菜单或标定页面。
- **OVERLOAD**：当前达到软件过载条件。

## 4.4 启动自检

正常产品构建上电后依次执行显示清除、六位数字段检查、上下状态指示检查、内部蜂鸣器短鸣和版本提示，然后进入称重。若某位数码管、灯或蜂鸣器在自检中明显异常，应记录现象并联系维护人员。

# 5. 按键说明

## 5.1 正常称重状态

| 按键 | 短按 | 长按 |
|---|---|---|
| FUNCTION | NET → GROSS → TARE → BATTERY 循环 | 进入普通菜单 |
| TARE | 执行去皮 | 清除皮重 |
| ZERO | 执行置零 | 复位日常零点 |
| STAR | 保留操作；当前版本无普通用户可见输出 | 显示 STATUS 页 |
| HASH | NET/GROSS 快速切换 | 无用户操作 |

## 5.2 菜单与编辑状态

| 按键 | 菜单浏览 | 数值/选项编辑 | 标定 |
|---|---|---|---|
| FUNCTION | 进入项目或执行命令 | 短按确认；长按退出菜单并取消当前未确认编辑 | 确认当前步骤 |
| TARE | 返回称重界面 | 取消当前编辑 | 取消整个标定会话 |
| ZERO | 无菜单浏览作用 | 数值编辑时移动选中位 | 标定质量编辑时移动选中位 |
| STAR | 上一项目 | 减小所选数字/切换到上一选项 | 减小标定质量 |
| HASH | 下一项目 | 增大所选数字/切换到下一选项 | 增大标定质量 |

> 同时按下多个按键不会被当作组合快捷键。高级菜单密码是依次短按，不是同时按下。

## 5.3 按键时间与重复

- 按键去抖约 30 ms。
- 长按判定约 1.5 s。
- STAR/HASH 按住约 0.6 s 后开始以固定间隔重复。
- 本版本没有逐渐加速功能；大数值应先用 ZERO 选择高位，再用 STAR/HASH 调整。
- 菜单约 30 s 无操作会自动退出；未确认的编辑被取消。

# 6. 基本称重操作

## 6.1 开机称重

1. 清空秤台并接通电源。
2. 等待启动自检结束。
3. 确认未显示 `noCAL`、`OL` 或 `Err`。
4. 观察重量和 STABLE 指示。
5. 需要改变显示单位时，按第 8.2 节操作并执行 SAVE。

正式预热时间和稳定时间尚未冻结，将在 Stage 6 计量性能验证完成后于 V1.0 说明书中补充。

## 6.2 ZERO 置零

ZERO 用于在允许零点范围内将当前空载偏移作为日常零点处理，不是对任意载荷强制归零。

**操作条件：**

- 已有有效标定；
- 当前重量稳定；
- 没有活动皮重；
- 当前毛重绝对值不超过 `ZrnG`；
- `ZrnG` 不为 0。

**步骤：**

1. 清空秤台并等待 STABLE。
2. 短按 ZERO。
3. 成功后显示回到零点附近并出现 ZERO 状态。
4. 若出现 `UnStAb`、`ZrAnGE`、`tArE`、`ZrOFF` 或 `ZrErr`，按第 15 章处理。

长按 ZERO 执行 RESET ZERO，清除当前日常零点偏移。ZERO 和 RESET ZERO 不写入 Flash，掉电后不保留。

**[图片占位：图 6-1 ZERO 流程，后续绘制正式流程图]**

## 6.3 TARE 去皮

TARE 将当前毛重保存为皮重，并显示净重。

**示例：**

| 状态 | 毛重 | 皮重 | 净重显示 |
|---|---:|---:|---:|
| 放置空容器 | 125.30 g | 0.00 g | 125.30 g |
| 短按 TARE | 125.30 g | 125.30 g | 0.00 g |
| 加入物料 | 325.30 g | 125.30 g | 200.00 g |

示例数值只用于解释毛重、皮重、净重关系。

**操作条件：** 已标定、重量稳定且未处于过载。成功 TARE 后，若当前页面为 NET，显示形成新的零点锚定以避免操作后瞬时跳数。

长按 TARE 清除皮重。清除后 NET 与 GROSS 将恢复为相同的称重基准。

**[图片占位：图 6-2 TARE 流程，后续绘制正式流程图]**

## 6.4 ZERO 与 TARE 的区别

| 对比项 | ZERO | TARE |
|---|---|---|
| 典型用途 | 消除空秤小偏移 | 扣除容器重量 |
| 允许范围 | 受 `ZrnG` 限制 | 不使用 `ZrnG`，但要求稳定且不过载 |
| 有皮重时 | 拒绝 | 可重新取得当前毛重作为皮重 |
| 对 NET/GROSS | 调整日常零点 | 使 NET = GROSS - TARE |
| 掉电保持 | 不保持 | 由 `trrEt` 决定，且状态改变后需 SAVE |

## 6.5 NET/GROSS 与单位切换

- HASH 短按：NET/GROSS 快速切换。
- FUNCTION 短按：在 NET、GROSS、TARE、BATTERY 页面间循环。
- 单位切换：进入普通菜单 `UnIt`，FUNCTION 进入，STAR/HASH 选择 kg、g 或 lb，FUNCTION 确认。
- 单位确认后显示 `rAnonL`，表示已在 RAM 中应用；需要掉电保持时执行 `SAUE`。

单位变化会重新按该单位的 `dP` 和 `dIU` 格式显示。同一物理重量切换单位时数值不同是正常现象。

# 7. 参数编辑方法

## 7.1 通用流程

```text
进入菜单项目
    ↓ FUNCTION
进入编辑
    ↓ ZERO 选择数字位（数值项目）
    ↓ STAR 减小 / HASH 增大
    ↓ FUNCTION 确认，或 TARE 取消
    ↓
显示 rAnonL：已在 RAM 应用
    ↓
需要掉电保持时执行 SAUE
```

## 7.2 六位数值选位

Stage 5F 支持全部六位选择。进入数值编辑后，ZERO 每短按一次按以下顺序循环：

```text
右 1 → 右 2 → 右 3 → 右 4 → 右 5 → 右 6 → 右 1
```

- 右 1 是最右侧数字，右 6 是最左侧数字。
- 当前选中位以约 250 ms 显示、250 ms 隐藏的方式闪烁。
- 如果选中位原本是前导空白，显示阶段会出现 `0`，隐藏阶段恢复空白，使该位置可辨认。
- 小数点始终保留，不随选中数字一起消失。
- 移动选中位或修改数值后，选中位立即进入可见阶段。
- STAR 减小所选位，HASH 增大所选位。
- 数值每次变化的实际步长还会乘以当前 `dIU`（1、2 或 5）。

**[图片占位：图 7-1 六位数值编辑光标，后续替换实拍序列]**

例如当前显示 `3000.00`，要改为 `500.00`，可用 ZERO 移动到百位/千位附近再调整，避免在最低位长时间重复按键。

## 7.3 选项与开关编辑

- `UnIt`、`FILt`、`Src`：STAR/HASH 循环选择。
- `L-En`、`bIn`、`bEH`、`bOK`：STAR/HASH 在 `On` 与 `OFF` 之间切换。
- `dIU`：按 1 → 2 → 5 循环。
- `dP`：按 0 → 1 → 2 → 3 → 4 → 5 循环；最终能否确认还受当前 CAP 和单位显示范围约束。

## 7.4 确认、取消与无效参数

- FUNCTION 短按：验证完整配置并提交到 RAM。
- TARE 短按：取消当前项目，恢复进入编辑前的值。
- FUNCTION 长按：退出菜单；正在编辑的未确认内容会被取消。
- 显示 `InUALd`：当前值或参数组合不合法，仪表未采用该编辑结果；这不等于仪表损坏。
- 显示 `UnItHI`：按当前单位/小数位无法表示该质量或量程，应调整 CAP、单位或 dP。
- 显示 `bUSY`：配置或标定资源正在被本地、Modbus 或 BLE 的另一会话使用。

## 7.5 Apply 与 SAVE

FUNCTION 确认成功后显示 `rAnonL`，表示参数已经在当前运行中生效。它不表示已经写入非易失存储。

> **重要：需要断电保持的参数修改完成后，请进入 `SAUE` 并按 FUNCTION。只有看到 `donE` 或 `noCHG`，才可认为保存流程正常结束。**

# 8. 普通菜单说明

## 8.1 进入与导航

1. 在正常称重页长按 FUNCTION。
2. 屏幕进入 `UnIt`。
3. HASH 查看下一项，STAR 查看上一项。
4. FUNCTION 进入/执行，TARE 返回称重。

普通菜单顺序：

```text
UnIt → PrOF → briGHt → trrEt → SAUE → EHIt → UnIt
```

## 8.2 普通菜单项目

# 9. 高级菜单说明

## 9.1 进入高级菜单

1. 长按 FUNCTION 进入普通菜单，保持在 `UnIt` 页。
2. 依次短按 `STAR → HASH → STAR → HASH`。
3. 相邻按键间隔不要超过约 1 s，整个序列不要超过约 4 s。
4. 成功后显示 `CAP`，表示已进入高级菜单。

高级菜单供现场调试和售后使用。错误设置可能导致无法置零、无法启用检重、显示 `InUALd` 或需要重新标定。

## 9.2 高级菜单树

```text
UnIt → PrOF → CAL → CAP → dIU → dP → FILt → StAb → ZrnG → OL
  → briGHt → SPd → GAIn → trrEt
  → L-En → Lo → Hi → HyS → Src → bIn → bEH → bOK
  → SAUE → rESEt → EHIt → UnIt
```

**[图片占位：图 9-1 高级菜单树，后续绘制正式流程图]**

## 9.3 计量与显示参数

| 显示 | 名称 | 当前编辑范围/选项 | 作用与限制 | SAVE |
|---|---|---|---|---|
| `CAP` | 量程 | 正数，六位显示范围内 | 仪表最大称量配置；不得超过当前硬件/传感器允许值 | 需要 |
| `dIU` | 分度数字 | 1、2、5 | 重量显示的最小变化步长数字 | 需要 |
| `dP` | 小数位 | 0～5 | 设置当前单位的小数点位置；更多小数位不等于更高准确度 | 需要 |
| `FILt` | 滤波模式 | 0～3 | 0 无；1 平均；2 IIR；3 中值+IIR | 需要 |
| `StAb` | 稳定保持时间 | 10～10000 ms | 影响稳定判断保持时间；完整稳定判断还受配置档其他参数影响 | 需要 |
| `ZrnG` | 置零范围 | 0～CAP | ZERO 允许的空载偏移范围；0 表示禁用 ZERO | 需要 |
| `OL` | 软件过载值 | 不低于 CAP，且受硬件上限约束 | 达到条件后显示/状态进入过载；不等于机械极限 | 需要 |
| `SPd` | 采样速率 | 只读 | 当前配置档采样速率；FUNCTION 显示 `rEAd` | 不可编辑 |
| `GAIn` | 增益 | 只读 | 当前配置档 ADC 增益；FUNCTION 显示 `rEAd` | 不可编辑 |

### CAP

CAP 应按配套传感器、秤体和应用定义设置。降低 CAP 不会提高传感器能力，提高 CAP 也不会扩大传感器机械安全范围。改变 CAP 可能使现有标定质量、OL、单位显示或报警参数不再合法；确认失败时显示 `InUALd`。

### dP 与 dIU

例如同一计数值可显示为 `500`、`500.0` 或 `500.00`。dIU 为 1、2、5 时，最低显示步长分别按最后一位的 1、2、5 变化。最终推荐 dP 和 dIU 将在 Stage 6 计量性能验证完成后于 V1.0 说明书中补充。

### FILt 与 StAb

滤波越强通常会使显示更平稳，但响应也可能更慢。StAb 用于稳定状态判断，会影响 ZERO、TARE、标定、检重和状态显示。V0.9 不给出最终推荐值；推荐设置将在 Stage 6 实测后确定。

### OL

OL 是软件过载判定阈值。达到过载时，重量显示 `OL`，红灯点亮，启用的蜂鸣器按报警节拍工作。移除载荷后，仪表先等待重新稳定，再恢复正常检重状态。

## 9.4 检重参数

| 显示 | 名称 | 选项/约束 | 说明 | SAVE |
|---|---|---|---|---|
| `L-En` | 检重使能 | OFF / On | 开启前必须保证 Lo < Hi 且 HyS 合法 | 需要 |
| `Lo` | 下限 | 支持负值，受六位显示限制 | 小于 Lo 为 LOW | 需要 |
| `Hi` | 上限 | 支持负值，受六位显示限制 | 大于 Hi 为 HIGH | 需要 |
| `HyS` | 检重回差 | ≥0，且不大于 (Hi-Lo)/2 | 抑制边界附近状态反复切换 | 需要 |
| `Src` | 检重重量源 | `nEt` / `GroSS` | 选择净重或毛重参与检重 | 需要 |
| `bIn` | 内部蜂鸣器 | OFF / On | 控制板载蜂鸣器报警输出 | 需要 |
| `bEH` | 外部蜂鸣器 | OFF / On | 控制外部蜂鸣器输出 | 需要 |
| `bOK` | OK 提示音 | OFF / On | 进入合格 OK 时短鸣一次 | 需要 |

## 9.5 恢复默认配置

`rESEt` 会写入默认配置并清除当前用户配置/标定状态，执行后通常需要重新设置参数和标定。仅由现场调试或售后人员使用。

1. 在 `rESEt` 页短按 FUNCTION，显示 `rESEt?`。
2. 长按 FUNCTION 确认，或短按 TARE 取消。
3. 等待 `rESEt`/`donE` 完成提示，不要断电。
4. 恢复后如显示 `noCAL`，按第 10 章重新标定。

# 10. 标定操作

## 10.1 标定用途

标定用于建立传感器原始信号与实际质量之间的关系。本仪表采用两点标定：

1. 空载零点；
2. 已知质量加载点。

标定成功后先应用到 RAM，再由单独的 SAVE 写入 Flash。标定过程不会自动保存。

## 10.2 标定前准备

1. 正确连接传感器并固定秤台。
2. 清除秤台上的物体，避免振动、碰触和气流干扰。
3. 准备质量值可靠的已知砝码。
4. 确认当前单位、CAP、dP、dIU 符合计划。
5. 标定质量必须大于 0、不超过 CAP，并能按当前单位/dP/dIU 准确表示。
6. 确认没有 Modbus 或 BLE 标定/配置会话占用仪表，否则可能显示 `bUSY`。

## 10.3 本地两点标定步骤

**步骤 1：进入标定**

1. 进入高级菜单。
2. 移动到 `CAL`。
3. 短按 FUNCTION。
4. 成功进入后显示 `UnLoAd`。若仍停留在 `CAL`，检查是否存在远程配置/标定会话，等待会话释放后重试。

**步骤 2：采集空载零点**

1. 确认秤台完全清空。
2. 短按 FUNCTION。
3. 屏幕显示 `CAL  0`，仪表等待独立的原始信号稳定窗口。
4. 稳定后自动采集零点，随后短暂显示当前单位并进入标定质量编辑。

**步骤 3：设置标定质量**

1. 屏幕显示上一次标定质量；若无有效记录，初始值取当前 CAP 可表示值。
2. ZERO 在六位之间循环选择。
3. STAR 减小，HASH 增大。
4. 短按 FUNCTION 确认标定质量。
5. 屏幕显示 `LoAd`。

**步骤 4：采集加载点**

1. 将设定质量的砝码平稳放在秤台上。
2. 等待机械状态稳定。
3. 短按 FUNCTION。
4. 屏幕显示 `CAL SP`，仪表等待稳定并自动采集加载点。
5. 计算成功后显示 `donE`，进入结果预览。

**步骤 5：应用与保存**

1. 在 `donE` 结果页短按 FUNCTION。
2. 显示 `rAnonL`，表示新标定已应用到 RAM。
3. 返回菜单后进入 `SAUE` 并短按 FUNCTION。
4. 等待显示 `donE` 或 `noCHG`。
5. 重新上电后用空载和已知砝码复查保存结果。

任何标定阶段均可短按 TARE 取消。应用前取消不会改变原有效标定。

**[图片占位：图 10-1 两点标定流程，后续绘制正式流程图]**

## 10.4 500 g 操作示例

以下仅演示操作方法，不表示所有量程都推荐使用 500 g：

1. 当前单位设为 g，确认 CAP/dP/dIU 可显示 `500.00`。
2. 进入 `CAL`，在 `UnLoAd` 下清空秤台并按 FUNCTION。
3. 零点采集后将标定质量编辑为 `500.00`。
4. 在 `LoAd` 提示下放置可靠的 500 g 砝码。
5. 按 FUNCTION，等待 `CAL SP` 后显示 `donE`。
6. 再按 FUNCTION 应用，随后执行 `SAUE`。

## 10.5 标定常见拒绝

| 现象 | 原因 | 处理 |
|---|---|---|
| `bUSY` 或无法从 `CAL` 进入 | 其他本地/Modbus/BLE 会话占用 | 取消远程会话或等待超时后重试 |
| `UnItEr` / `UnItHI` | 当前单位显示无法表示 CAP 或标定质量 | 调整单位、dP、dIU 或 CAP |
| 长时间停留 `CAL  0` / `CAL SP` | 原始信号未满足标定稳定条件 | 检查机械振动、接线和载荷 |
| `CALErr` / `Err` | 标定点顺序、信号跨度或数据不合法 | 取消，检查砝码与传感器后重新开始 |
| 应用后掉电恢复旧标定 | 未执行 SAVE | 重新标定/应用后执行 `SAUE` |

标定稳定窗口的内部实现已通过当前硬件流程验证，但不作为最终产品“稳定时间”规格。最终稳定时间将在 Stage 6 计量性能验证完成后于 V1.0 说明书中补充。

# 11. 上下限检重与报警

## 11.1 启用顺序

建议按以下顺序设置，避免 `L-En` 因默认 Lo/Hi 关系无效而显示 `InUALd`：

1. 设置 `Src`（NET 或 GROSS）。
2. 设置 `Lo`。
3. 设置 `Hi`，确保 Lo < Hi。
4. 设置 `HyS`，确保 HyS ≤ (Hi-Lo)/2。
5. 设置 `bIn`、`bEH`、`bOK`。
6. 最后将 `L-En` 设为 On。
7. 执行 `SAUE`。

## 11.2 基本判定

在取得稳定分类时：

```text
weight < Lo              → LOW
Lo ≤ weight ≤ Hi         → OK
weight > Hi              → HIGH
```

**[图片占位：图 11-1 LOW/OK/HIGH 状态区间，后续绘制正式示意图]**

| 状态 | 黄灯 | 绿灯 | 红灯 | 蜂鸣器 |
|---|---|---|---|---|
| DISABLED | 灭 | 灭 | 灭 | 静音 |
| LOW | 亮 | 灭 | 灭 | 静音 |
| OK | 灭 | 亮 | 灭 | `bOK=On` 时进入 OK 短鸣约 100 ms |
| HIGH | 灭 | 灭 | 亮 | 启用通道约 250 ms 响/250 ms 停 |
| OVERLOAD | 灭 | 灭 | 亮 | 启用通道约 250 ms 响/250 ms 停 |
| FAULT | 灭 | 灭 | 亮 | 启用通道约 250 ms 响/250 ms 停 |

这里的时间是固件功能节拍，Stage 5E 通过可听/可观察周期确认，未进行仪器级绝对波形计量。

## 11.3 稳定门控

- 尚未取得过稳定分类且当前不稳定时，检重状态为 DISABLED，三色灯全灭。
- 已取得稳定分类后出现短时不稳定，仪表可保持上一次合格分类，避免灯和蜂鸣器频繁抖动。
- 快速加载时，灯何时点亮取决于何时取得或保留稳定分类，因此慢放与快速放置可能表现不同。
- OVERLOAD 和 FAULT 的优先级高于普通 LOW/OK/HIGH。
- 标定期间普通检重灯熄灭；若同时发生 OVERLOAD，过载仍保持高优先级。

## 11.4 HyS 检重回差

示例：

```text
Lo = 499.00 g
Hi = 501.00 g
HyS = 0.20 g
```

- 进入 LOW 后，重量必须恢复到 **499.20 g 及以上**才返回 OK；若直接超过 Hi，可进入 HIGH。
- 进入 HIGH 后，重量必须下降到 **500.80 g 及以下**才返回 OK；若直接低于 Lo，可进入 LOW。

**[图片占位：图 11-2 HyS 回差示意，后续绘制正式示意图]**

HyS 是检重状态回差，不是传感器的计量迟滞。计量迟滞将在 Stage 6 计量性能验证完成后于 V1.0 说明书中补充。

## 11.5 Src：NET 与 GROSS

```text
毛重 GROSS = 秤台当前总载荷
皮重 TARE  = 已扣除的容器重量
净重 NET   = GROSS - TARE
```

**[图片占位：图 11-3 NET/GROSS/TARE 关系，后续绘制正式示意图]**

例如容器 125.30 g、物料 500.00 g：

- `Src=nEt`：检重值约为物料净重 500.00 g。
- `Src=GroSS`：检重值约为总毛重 625.30 g。

使用 TARE 时必须确认 Src，否则可能出现称重显示与检重灯看似不一致的情况。

# 12. 参数保存与掉电恢复

## 12.1 RAM 生效与 Flash 保存

| 操作 | 当前运行 | 掉电后 |
|---|---|---|
| FUNCTION 确认菜单参数 | 立即生效 | 未 SAVE 时可能恢复旧值 |
| 标定结果 FUNCTION 应用 | 立即生效 | 未 SAVE 时恢复旧标定 |
| `SAUE` 成功 | 保持当前值 | 从新记录恢复 |
| ZERO / RESET ZERO | 立即生效 | 不保持 |
| TARE / CLEAR TARE，`trrEt=0` | 立即生效 | 不恢复皮重 |
| TARE / CLEAR TARE，`trrEt=1` 且随后 SAVE | 立即生效 | 恢复已保存皮重状态 |

## 12.2 执行 SAVE

1. 完成所有参数确认或标定应用。
2. 进入 `SAUE`。
3. 短按 FUNCTION。
4. 保存过程中显示 `SAUE`，不要断电。
5. 显示 `donE`：新记录保存成功。
6. 显示 `noCHG`：当前配置与已保存记录无变化。
7. 显示 `ErrSAU`：保存失败或供电条件不允许，应检查供电后重试。

固件使用两个 Flash 配置槽和 CRC/序列记录进行恢复。用户无需选择槽位，也不应直接操作 Flash 地址。

## 12.3 掉电后的验证

对重要修改建议执行：

1. SAVE 完成后正常断电。
2. 重新上电。
3. 检查单位、CAP、Lo/Hi/HyS、蜂鸣器设置和标定是否保持。
4. 空载及已知砝码复查。

# 13. RS232 / RS485 通讯使用

## 13.1 协议与默认值

当前通讯使用 Modbus RTU，Register Map 版本为 `0x0103`。

| 项目 | 新设备/默认配置 | 说明 |
|---|---|---|
| 设备地址 | 1 | 可由通讯配置修改；实际值以当前仪表配置为准 |
| 波特率 | 115200 bit/s | 实际值以当前仪表配置为准 |
| 数据位 | 8 | 固定应用数据位 |
| 校验 | None | 支持配置 None/Even/Odd |
| 停止位 | 1 | 支持配置 1/2 |
| 响应延时 | 0 ms | 默认值 |
| 建议轮询间隔 | 50 ms | 通讯配置字段；现场可按网络负载调整 |
| 字序 | 高字在前 | 多寄存器值以当前配置为准 |

当前实板验证使用地址 1、115200、8N1。用户保存过通讯配置后，必须以仪表当前值为准。

## 13.2 支持功能码

| 功能码 | 名称 | 用途 |
|---:|---|---|
| FC03 | Read Holding Registers | 读取重量、状态、配置和诊断 |
| FC06 | Write Single Register | 写单个允许的配置/控制字 |
| FC16 | Write Multiple Registers | 原子写入多寄存器值和成组配置 |

不支持的功能返回异常 01；非法/只读地址返回 02；非法值或数量返回 03；设备失败返回 04；资源占用返回 06。CRC 错误或地址不匹配时仪表不响应。

## 13.3 常用读取

| PDU 地址 | 内容 | 说明 |
|---|---|---|
| `0000-0001` | 当前面板显示值 | 可能受稳定显示保持影响 |
| `0002` | 小数位 | 与显示值配合解释 |
| `0003` | 单位 | 0=kg，1=g，2=lb |
| `0004-0005` | 状态 | 稳定、过载等 |
| `000E` | Register Map | 应读到 `0x0103` |
| `000F` | Firmware | 当前为 `0x050A` |
| `0010-001B` | NET/GROSS/TARE | 有符号 64 位，单位 µg |
| `0220-023B` | 检重配置和实时状态 | 包含灯、蜂鸣器相位、dirty |

PLC 的 4xxxx 表示法可能把 PDU 地址 0000 写作 40001。上位机软件采用零基还是一基地址必须查其说明，避免整体偏移一位。

## 13.4 配置和命令

配置写入采用“暂存 → 验证 → APPLY_RAM → SAVE”流程。多字 64 位质量参数必须用 FC16 一次写完整四个寄存器；FC06 或不完整 FC16 会被拒绝。

```text
BEGIN 配置编辑
  → 写入 staged 寄存器
  → VALIDATE
  → APPLY_RAM
  → 需要掉电保持时 SAVE
```

APPLY_RAM 不等于 SAVE。异步命令返回 ACCEPTED 只表示已受理，不表示 Flash 已完成，客户端应读取响应/保存状态确认结束。

## 13.5 通讯测试建议

1. 先用 FC03 读取 `000E`，确认返回 `0x0103`。
2. 读取 `000F`，确认固件值与现场记录一致。
3. 读取实时重量块，确认 CRC、地址和字序。
4. 再进行配置写入；写入前保存当前值用于回退。
5. 在 RS485 多节点网络上逐台使用唯一地址。

完整寄存器和命令邮箱定义参见 `Docs/MODBUS_REGISTER_MAP_V1.md`。本说明书不替代通信协议手册。

# 14. BLE 无线通讯使用

## 14.1 连接关系

仪表内部使用 W02 作为 BLE 透明传输模块。W02 原厂基础信息为 BLE 5.2、UART、FFE0/FFE1/FFE2，模块 UART 默认 9600/8/N/1。当前仪表固件通过 USART1 以 9600 8N1 与 W02 通讯。

```text
手机/电脑 BLE 客户端
   ↕  FFE2 写入命令 / FFE1 Notify 接收
W02 透明传输模块
   ↕  UART 9600 8N1
称重仪表 BLE Protocol V1
```

**[图片占位：图 14-1 BLE 连接逻辑，后续绘制正式示意图]**

普通用户应使用仪表 BLE Protocol V1，不应把 W02 AT 命令当作产品业务协议。

## 14.2 GATT 服务

| UUID | 方向 | 用途 |
|---|---|---|
| `FFE0` | 服务 | W02 主服务 |
| `FFE1` | 仪表 → 客户端 | Notify 实时数据和命令响应 |
| `FFE2` | 客户端 → 仪表 | Write / Write Without Response 命令请求 |

FFE1 通知和 FFE2 写入边界不等于协议帧边界。客户端必须把接收数据看作连续字节流，根据同步头、长度和 CRC 重组帧。

## 14.3 连接步骤

1. 打开手机或电脑 BLE。
2. 搜索现场 W02 设备。设备名称可能包含 W02 和模块编号，不能仅靠名称确认唯一设备。
3. 连接设备并发现 `FFE0` 服务。
4. 对 `FFE1` 开启 Notify。
5. 先接收实时数据，或通过 `FFE2` 发送 GET_DEVICE_INFO。
6. 确认返回 Protocol V1、固件 `0x050A`、Schema 2、Map `0x0103`。
7. 执行修改类命令前记录原配置，并在 APPLY 后按需发送 SAVE_CONFIG。

实板验证设备曾显示为 `W02_008324`，但该名称/地址属于测试模块示例，不应作为所有产品的固定名称或地址。

## 14.4 实时数据

| 消息 | 类型 | 周期 | 主要内容 |
|---|---:|---:|---|
| FAST_WEIGHT | `0x01` | 约 5 Hz | 显示质量、净重、毛重、皮重、稳定、过载、单位、dP、dIU |
| SLOW_STATUS | `0x02` | 约 1 Hz | 原始值、容量、OL、滤波、配置档、故障、dirty |
| CHECKWEIGH_STATUS | `0x03` | 约 1 Hz | LOW/OK/HIGH、Src、灯和蜂鸣器状态 |
| COMMAND_REQUEST | `0x80` | 按需 | 客户端请求 |
| COMMAND_RESPONSE | `0x81` | 按需 | 命令结果 |

## 14.5 支持的用户命令

| 类别 | 当前支持 |
|---|---|
| 查询 | GET_DEVICE_INFO、GET_ACTIVE_CONFIG、GET_CALIBRATION_STATE |
| 称重操作 | TARE、CLEAR_TARE、ZERO、RESET_ZERO、SET_WEIGHT_VIEW、SET_DISPLAY_UNIT |
| 配置 | BEGIN、SET MASS、SET UNIT DISPLAY、SET PROFILE FIELD、SET FIELD、VALIDATE、APPLY、DISCARD、SAVE |
| 标定 | BEGIN、SET MASS、CAPTURE ZERO、CAPTURE LOAD、APPLY、CANCEL |

BLE 当前不支持 Factory Reset、通讯参数 Apply、OTA、AT、FF12 和 Runtime Drift 控制。

## 14.6 BLE 标定注意事项

- BEGIN 成功后使用返回的 `session_id` 完成后续修改命令。
- 零点和加载点必须分别满足稳定条件。
- APPLY 只写 RAM；SAVE_CONFIG 是唯一的 Flash 保存操作。
- 标定会话约 120 s 无有效修改命令会自动取消；仅 GET STATE 或遥测不会延长会话。
- BLE、Modbus 和本地面板只允许一个标定/配置所有者；冲突时返回 BUSY。
- 重试必须复用相同 transaction_id 和完全相同的请求，避免重复执行；同一 ID 携带不同内容会返回 TRANSACTION_CONFLICT。

完整帧格式、CRC、字段偏移和参考帧参见 `Docs/BLE_PROTOCOL_V1.md`。

# 16. 常见问题与故障排查

## 16.1 常见问题

### Q1：为什么开机显示 `noCAL`？

当前没有有效标定记录，可能是首次使用、恢复默认、保存记录无效或更换了配置。按第 10 章完成两点标定、应用并 SAVE。

### Q2：ZERO 和 TARE 有什么区别？

ZERO 用于允许范围内的空秤偏移，受 ZrnG、稳定和皮重状态限制；TARE 用于扣除容器重量。ZERO 不可在皮重活动时执行。

### Q3：为什么按 TARE 后显示 0？

仪表把当前毛重作为皮重，净重 = 毛重 - 皮重，因此当前 NET 显示为 0。按 FUNCTION 查看 TARE/GROSS，或长按 TARE 清除皮重。

### Q4：为什么修改参数后断电恢复原值？

FUNCTION 只把编辑结果应用到 RAM。必须进入 `SAUE` 并等待 `donE`/`noCHG`。

### Q5：为什么显示 `InUALd`？

完整配置验证失败。常见原因是 CAP 与 OL 不合法、Lo 不小于 Hi、HyS 超过区间一半、dP/dIU 无法表示 CAP，或标定质量超过 CAP。

### Q6：为什么 `L-En` 无法打开？

先设置 Lo、Hi 和 HyS，保证 Lo < Hi 且 HyS ≤ (Hi-Lo)/2，再打开 L-En。

### Q7：为什么 Lo/Hi 不能保存？

单项数值可编辑不表示组合合法。确认 Lo < Hi，并检查 HyS、单位、小数位和显示范围。

### Q8：为什么 HyS 设置失败？

HyS 必须非负且不超过 (Hi-Lo)/2。它是检重状态回差，不是计量迟滞。

### Q9：为什么红灯亮并周期报警？

当前可能为 HIGH、OVERLOAD 或 FAULT。先看重量是否超过 Hi/OL；移除载荷仍不恢复时检查传感器接线和错误提示。

### Q10：为什么没有蜂鸣声？

检查 bIn/bEH 是否开启。LOW 本来不报警；OK 仅在 bOK 开启且新进入 OK 时短鸣一次；持续处于 OK 不重复鸣叫。

### Q11：为什么切换 NET/GROSS 后检重状态变化？

检重实际使用 Src 指定的 NET 或 GROSS。使用容器去皮时两者可能相差整个皮重值。

### Q12：为什么 dP 增加后不代表准确度提高？

dP 只改变显示格式。真实计量性能还取决于传感器、机械结构、噪声、标定、分度和环境；最终结论待 Stage 6。

### Q13：怎样看清高位正在编辑？

Stage 5F 已支持六位选位和闪烁。ZERO 依次选择右 1 到右 6；前导空白位会用 0/空白闪烁提示。

### Q14：更换传感器后是否需要重新标定？

需要。更换传感器或改变力学结构后，原始信号与质量关系改变，应重新标定并 SAVE。

### Q15：为什么进入 CAL 后按键无响应或不能退出？

先短按 TARE 取消。若仍在 CAL，检查是否有 BLE/Modbus 会话占用，并等待其取消或超时。Stage 5C-D 已修复过异步 BUSY 导致本地 CAL 菜单失活的问题；确认固件为本手册适用版本。

### Q16：为什么慢放和快速放置时检重灯点亮时机不同？

检重状态受稳定门控。没有历史分类时必须等待稳定；已有分类时不稳定阶段可保留先前状态。只要最终 LOW/OK/HIGH 和报警符合规则，这种时机差异属于当前设计。

## 16.2 故障排查表

| 现象 | 优先检查 | 建议处理 |
|---|---|---|
| 无显示 | 电源、端子、线缆 | 断电检查；不要在不明电压下反复试接 |
| 某位/某段不亮 | 启动自检表现 | 记录位置，联系面板/驱动维修 |
| 重量无变化 | 传感器 E/S 接线、机械受力 | 断电检查接线，确认载荷确实传到传感器 |
| 重量方向相反 | S+/S- 定义、标定方向 | 由调试人员核对接线并重新标定 |
| 重量持续跳动 | 机械振动、屏蔽、接地、传感器、Filter | 排除环境与接线；推荐 Filter 待 Stage 6 |
| ZERO 被拒绝 | STABLE、TARE、ZrnG、noCAL | 按提示逐项处理 |
| TARE 被拒绝 | STABLE、OL、noCAL | 稳定且不过载后重试 |
| 一直显示 OL | 实际超载、OL/CAP 配置、传感器异常 | 立即卸载，检查参数和接线 |
| 黄绿红灯全灭 | L-En OFF、未稳定分类、标定进行中 | 检查 L-En，等待稳定，退出标定 |
| 通讯无响应 | 接口、电气连接、地址、波特率、校验、CRC | 从默认 1/115200/8N1 和 FC03 `000E` 排查 |
| Modbus 值错位 | 零基/一基地址、字序 | 检查 PLC 40001 映射和当前字序 |
| BLE 搜索不到 | 客户端蓝牙、W02 供电、距离、系统蓝牙状态 | 重启客户端蓝牙，靠近设备，避免多主机占用 |
| BLE 收到碎片帧 | 把 Notify 当成完整帧 | 使用流解析器按 A5 5A、长度和 CRC 重组 |
| SAVE 显示 ErrSAU | 供电不稳或 Flash 操作失败 | 保持供电，重试；重复失败则维修 |

# 17. 维护与重新标定

## 17.1 日常检查

- 检查传感器、秤台、紧固件和线缆是否松动、受潮、挤压或破损。
- 检查空载是否能够回到预期零点，已知质量检查是否出现异常变化。
- 检查黄绿红灯、内部/外部蜂鸣器和启动自检是否正常。
- 检查通讯端子和屏蔽接地，尤其是长线 RS485 现场。
- 重要参数修改后记录版本、日期、操作者和 SAVE 结果。

## 17.2 需要重新标定的情况

- 更换传感器或仪表主板；
- 改变秤台、受力结构、安装位置或传力件；
- 恢复默认配置后显示 `noCAL`；
- 已知质量检查出现不可接受偏差；
- 维修后影响了传感器、模拟前端或机械结构。

## 17.3 重新标定建议

1. 先导出/记录当前 CAP、dP、dIU、单位、检重参数和通讯参数。
2. 检查机械结构与接线，不要用标定掩盖硬件故障。
3. 按第 10 章重新标定。
4. 执行 SAVE。
5. 掉电重启后复查空载和已知质量。
6. 记录固件标签 `stage5f-ui-tested` 和说明书版本 V0.9。

定期校验周期应按最终产品、行业和现场管理要求制定；V0.9 不在 Stage 6 完成前给出统一周期。
